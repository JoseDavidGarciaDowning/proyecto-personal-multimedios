# Referencias

## Framework — Vue 3

### Cursos y tutoriales

- **[Vue.js: De cero a experto](https://cursos.devtalles.com/courses/vue-js)** — Fernando Herrera, DevTalles. Curso completo de Vue 3 con Composition API, Pinia, Vue Router y testing. Principal recurso para aprender el framework.

- **[certificates.dev — Cheat Sheets](https://certificates.dev/#top)** — Hojas de resumen rápido de Vue 3, Composition API y patrones comunes. Usadas como referencia rápida durante el desarrollo.

### Documentación oficial

- **[Vue 3 Documentation](https://vuejs.org/guide/introduction.html)** — Guía oficial de Vue 3: Composition API, `<script setup>`, reactividad, ciclo de vida de componentes, `watch`, `computed` y directivas.

- **[Pinia Documentation](https://pinia.vuejs.org/)** — Documentación oficial de Pinia para manejo de estado global.

- **[Vite Documentation](https://vite.dev/guide/)** — Documentación de Vite como bundler y dev server.

- **[Tailwind CSS v4 Documentation](https://tailwindcss.com/docs)** — Documentación oficial de Tailwind CSS para los estilos de la aplicación.

- **[MDN Web Docs](https://developer.mozilla.org/es/)** — Referencia de JavaScript, TypeScript, CSS y APIs web (`fetch`, `localStorage`, `Audio`, `matchMedia`).

### Herramientas de IA

- **[Claude (Anthropic)](https://claude.ai/)** — Usado como apoyo para entender conceptos del framework, interpretar errores del compilador y explorar cómo resolver problemas específicos con Vue 3 y TypeScript. El código producido fue comprendido, modificado y validado antes de integrarlo al proyecto.
