# DevChallenge

Quiz educativo interactivo desarrollado con Vue 3 + TypeScript + Vite.

## Stack

- **Vue 3** con Composition API (`<script setup>`)
- **TypeScript**
- **Vite** como bundler
- **Pinia** para manejo de estado global
- **Tailwind CSS v4** para estilos

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
